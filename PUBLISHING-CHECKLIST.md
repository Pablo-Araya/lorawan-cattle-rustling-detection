# Publication checklist

- [ ] Confirm authors' consent and ownership, including university and third-party rights.
- [ ] Verify final paper title, authors, publication venue, DOI and canonical URL.
- [ ] Replace all placeholder media with **genuine** project assets.
- [ ] Confirm that media depict the controlled laboratory validation described by the paper.
- [ ] Remove or blur private farm coordinates, identities, TTN/Azure credentials, device identifiers as needed, notification tokens and sensitive information.
- [ ] Review screen text for discrepancies between presentation and final article; the **paper governs**.
- [ ] Do not claim validation on cattle, measured cost advantage, theft-detection accuracy or operational field deployment.
- [ ] Avoid publishing pinouts, proprietary firmware, electrical schematics and processing logic.
- [ ] Ensure any third-party logos, maps and screenshots have appropriate attribution/permission.
- [ ] Review copyright notice and repository ownership with all authors and university IP office.
- [ ] Enable GitHub Pages using main / (root).
- [ ] Test mobile and desktop rendering, videos, accessibility labels, and all links.
- [ ] If citing the site from the paper, verify editorial permission to insert the link.
