# LoRaWAN-Based IoT Prototype for Cattle Rustling Detection

**Supplementary visual and experimental documentation** for:

> *Development of a LoRaWAN-Based IoT Prototype for the Early Detection of Events Compatible with Cattle Rustling in Bovine Herds*

**Authors:** Pablo Araya del Pino · Cecilia Gamonal Vera · Jorge Retamal Pinto  
**Institution:** Universidad Andrés Bello, Chile · 2026

This repository contains a **static GitHub Pages presentation** for photographic, diagrammatic and video evidence corresponding to the article's controlled laboratory validation. **The paper is authoritative.** The website is not source-code distribution, field validation, nor a claim of cattle-theft prevention effectiveness.

## Scientific consistency

- **Two** laboratory prototypes; **379** decoded uplinks; **98.7%** combined LoRaWAN delivery; **79.2%** indoor GPS fix; **3/3** induced tampering events; **16** automatic alerts.
- End-to-end tampering notification time **approximately 17 seconds** in three tests; not a guarantee.
- **15** defined alert types: five critical, seven high, three medium.
- Optical heart rate and external temperature sensing are **exploratory**, tested using human tissue as a biological substitute, not validated on cattle.
- No cattle field deployment, real cattle-rustling accuracy assessment, cost validation, full-scale network validation or SAG/SIPEC integration.
